# IARA++ — Laboratório de Inteligência Artificial, Robótica e Algoritmos

Laboratório de pesquisa da UFABC, coordenado pelo Prof. Dr. Mateus Coelho Silva, com atuação em Edge AI, Sistemas Cíber-Físicos, Robótica, IoT e Indústria 4.0.

🌐 Site institucional: https://iarapp.pesquisa.ufabc.edu.br/
📄 Publicações: veja o site institucional para a lista oficial

---

## Como este GitHub está organizado

| Repositório | O que é |
|---|---|
| [`lab-guidelines`](https://github.com/iara-ufabc/lab-guidelines) | Onboarding, normas, templates, como pedir um novo repositório |
| [`shared-tools`](https://github.com/iara-ufabc/shared-tools) | Bibliotecas e utilitários reaproveitáveis entre projetos |
| [`lab-infra`](https://github.com/iara-ufabc/lab-infra) | Infraestrutura física/compartilhada do lab |
| [`papers`](https://github.com/iara-ufabc/papers) | Rascunhos de artigos em desenvolvimento |
| [`datasets`](https://github.com/iara-ufabc/datasets) | Dados coletados pelos projetos do lab |

**Quer criar um projeto novo?** Abra uma issue no [`lab-guidelines`](https://github.com/iara-ufabc/lab-guidelines/issues/new/choose) usando o template "Solicitar novo repositório".
